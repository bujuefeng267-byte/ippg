# rPPG V2.1 代码修复与指标变化

本次修复后，UBFC subject1 的融合心率 MAE 从退步版本 V2 的 **3.660 降到 2.494 bpm**，有效输出从 **35/44 恢复到 40/44**。与更早的 POS 离线 DP 基线相比，MAE 仅降低 **0.067 bpm（2.61%）**。共同窗口的融合波形 SNR 没有提高，本轮主要修复了心率与实际波形不一致的问题。

这些是已看过数据上的回归结果。今天新增的数据集尚未用于本次修改，需要作为独立验证，才能判断运动条件下的提升能否推广。

## 本次改了什么

| 代码修复 | 解决的问题 |
|---|---|
| 候选分组确定化 | 遍历顺序或诊断编号改变时，分组结果不再改变；中心必须等于最终成员的加权中位数 |
| 从实际融合波形重新计算心率 | 区域候选只用于提议和波形构建，最终局部谱峰与 DP 心率来自保存的 `base` 信号 |
| 追踪实际参与融合的区域 | 被剔除的区域不再影响采样来源；真实贡献中的任意插值会被记录 |
| 拒判时清空最终 HR | 原始谱峰另存诊断列，避免把拒判候选误读成有效心率 |
| 提议、波形生成和最终接受分别记录 | 能区分自行生成的窗口、由邻窗覆盖的窗口以及最终接受的 HR |

没有改变前端人脸采样、POS/CHROM、滤波、DP 代价或各数值阈值。整条链路仍然离线：最终 DP 会使用未来窗口，重叠融合也可能使用后面的信号。新版局部谱峰分支同样来自离线预处理波形。

## 指标与实测变化

以下心率指标针对 **`videos/ubfc_subject1/vid.avi`**，1547 帧、约 52.86 秒。参考为配套 UBFC 设备 HR，非直接 ECG。使用 10 秒窗口、约 1 秒步长，共 44 个参考可计算窗口；参考只在预测完成后评分。

| 指标及含义 | 更早 POS DP 基线 | V2 融合 | V2.1 融合 DP | V2 → V2.1 |
|---|---:|---:|---:|---|
| MAE：平均绝对心率误差，越小越好 | 2.561 bpm | 3.660 bpm | 2.494 bpm | 降低 31.86% |
| RMSE：更重视大误差，越小越好 | 3.061 bpm | 5.376 bpm | 2.986 bpm | 降低 44.46% |
| C_out：全部窗口中有效输出的比例 | 90.91%（40/44） | 79.55%（35/44） | 90.91%（40/44） | 增加 11.36 个百分点 |
| P5：有效输出中误差 ≤5 bpm 的比例 | 97.50%（39/40） | 68.57%（24/35） | 97.50%（39/40） | 增加 28.93 个百分点 |
| R5：全部参考窗口中误差 ≤5 bpm 的比例 | 88.64%（39/44） | 54.55%（24/44） | 88.64%（39/44） | 增加 34.09 个百分点 |
| 有符号平均偏差：预测减参考 | −0.750 bpm | +0.782 bpm | −0.800 bpm | 从高估变为低估，绝对偏差略增 |
| 描述性 Bland–Altman 一致性界限 | [−6.641, 5.140] bpm | [−9.796, 11.360] bpm | [−6.511, 4.910] bpm | 范围收窄 |
| 95% 分位绝对误差 | 4.630 bpm | 12.963 bpm | 4.630 bpm | 降低 |
| 最大绝对误差 | 5.344 bpm | 14.547 bpm | 5.344 bpm | 降低 |

窗口相互重叠，上述一致性界限和误差分布仅作描述，不能当成人群统计显著性证明。C_out 不等于准确率；R5 保留全部参考窗口作分母，可以防止只靠拒绝困难窗口把 MAE 做低。

在三个版本都有效的 **35 个相同窗口** 上，MAE 分别为 **2.362 → 3.660 → 2.286 bpm**；因此 V2.1 相对 V2 的改善并非只由统计窗口变化造成。DP 路径仍分别由各自完整可用序列计算，不能把共同窗口评价解释成隔离未来信息的实验。

先前误差最大的三个窗口，中心约 29.781、30.771、31.762 秒，V2 输出 124、124、126 bpm；V2.1 DP 输出 107、108、108 bpm，绝对误差恢复到 3.768、3.153、3.453 bpm，均在 5 bpm 以内。

为同时保留局部估计对照，V2.1 局部谱峰的 MAE 为 **2.644 bpm**、RMSE **3.392 bpm**、P5 **75.00%**、R5 **68.18%**。相对更早 POS 局部谱峰，虽然 MAE 从 3.209 降低，P5 却从 80.00% 降到 75.00%；不能说所有分支、所有指标都上涨。完整七分支表包含 POS/CHROM 的局部谱峰和离线 DP。

## 波形质量是否提高

| 波形指标 | 本次结果 | 解释 |
|---|---|---|
| 参考基频 SNR，V2 与 V2.1 共同 35 窗 | 中位数均为 −2.979 dB；逐窗增益中位数 0.000 dB | 本轮没有证明波形本身进一步改善 |
| V2.1 相对更早 POS，共同 40 窗 | 逐窗 SNR 增益中位数 +0.815 dB；30/40 窗提高 | 属于多区域融合相对旧基线的结果，不全是本轮代码修复新增收益 |
| V2.1 相对更早 CHROM，共同 40 窗 | 逐窗 SNR 增益中位数 +0.500 dB | 同上 |
| 波形相关系数、形态恢复、绝对伪影能量 | NA | 尚无经验证的同步波形对齐及干净真值，不编造数值 |

SNR 的口径为 0.7–3.5 Hz 带内，参考心率基频 ±0.1 Hz 的功率与带内剩余功率之比；全窗 Hann、NFFT=8192。剩余部分也可能含真实谐波，不能全部命名为运动伪影。

如果各算自己的有效窗口，V2 SNR 中位数为 −2.979 dB（35 窗），V2.1 为 −3.422 dB（40 窗）；这来自窗口集合扩大，不能直接判为波形退步。共同窗口的结果基本相同。

## 五个视频的有效输出

| 视频 | 更早 POS DP | V2 | V2.1 | 可以确认什么 |
|---|---:|---:|---:|---|
| `Video_20260904_145402918.avi` | 36/39（92.31%） | 31/39（79.49%） | 36/39（92.31%） | 覆盖恢复；无同步参考，精度为 NA |
| `Video_20260907_171742478.avi` | 14/42（33.33%） | 12/42（28.57%） | 12/42（28.57%） | 未改善，仍低于旧基线 |
| UBFC subject1 `vid.avi` | 40/44（90.91%） | 35/44（79.55%） | 40/44（90.91%） | 有设备 HR，可计算上表误差 |
| Kaggle subject001 完整 `video.mov`，约 429.33 秒 | 416/419（99.28%） | 246/419（58.71%） | 323/419（77.09%） | 增加 18.38 个百分点，仍低于旧基线；本地无配对参考 |
| `self_test_72bpm.mp4` | 7/11（63.64%） | 7/11（63.64%） | 7/11（63.64%） | 合成颜色调制，接受窗 MAE=0；不代表人体精度 |

V2.1 在 UBFC 的 40 个有效窗口中，34 个自行生成波形、6 个由相邻窗口完整覆盖；Kaggle 分别为 145 和 178 个。覆盖增加的一部分来自对已经融合出的连续波形重新估计 HR，不能解释为增加了同等数量的独立皮肤观测。

固定的五种 RGB 合成压力场景中，V2.1 在四种场景输出 47/51 窗、接受窗 MAE=0；全区域共同扰动场景仍为 **0/51 输出**。这些混合信号不包含真实头动、模糊、遮挡或人群差异，说明仍有失败模式。

## 验证与后续数据

最终冻结版本通过 **45 项测试**。五视频均正常退出；旧 POS/CHROM 预测逐值复现；评价器独立从保存的融合波形复算局部和 DP 心率，并独立重建实际区域贡献的 observed/interpolated 标记。首轮与最终版共 50 对 CSV 审计通过，有效 HR、接受状态和波形均未改变；最终整理仅明确拒判谱峰及诊断字段的含义。

今天增加数据时，优先保留原始人脸视频、同步 PPG/ECG/设备 HR 及时间戳、受试者与动作标签。先检查参考同步和视频帧率，再按受试者划分开发与测试集，冻结本版后一次性跑测试集。没有同步参考的视频仍可以做采样和覆盖分析，但误差和参考 SNR 必须留 NA。

建议下一阶段由新增数据决定改动优先级：先处理人脸丢失、局部遮挡和可变帧率造成的采样问题，再评价实际信号质量加权及共同扰动拒判问题。此次没有根据单个 UBFC 的真值重新选择区域、改阈值或训练模型。
