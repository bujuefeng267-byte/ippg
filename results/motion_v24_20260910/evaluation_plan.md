# V24 固定评测方案

目标是在保留像素跟踪、局部筛选和明确失败回退的前提下，提高 V22 的心率精度与可用覆盖。先前 V23 的结果表明，增加机制本身不能证明性能提升；本轮必须同时对账误差、拒判、实际保存波形和新增窗口。

**当前状态：候选参数、11 个核心源码哈希、测量规则及主候选已在 V24 推理前冻结。** 主候选为 guarded_fusion_gap10，gap15 对应选项为 guarded_fusion_gap15。根任务已确认代码审查和 85/85 项测试通过，正式 runner 另存测试回执。本任务未启动推理、未改旧数据。可执行定义与冻结时间见 [evaluation_protocol.json](./evaluation_protocol.json)，前稿保留在 evaluation_protocol_pre_freeze.json。评价器适配实现仍在准备，将在查看任何 V24 评分前固定实现哈希并通过旧基线复算；公式、参考和升级门槛先于推理固定。

## 一轮四个候选

| 候选名 | 拟定结构 | 对照基线 |
|---|---|---|
| bounded_tracking_gap10 | 保留跟踪/局部筛选，为 log 相对颜色引入低频基线锚定，限制累积漂移；失败显式回退 | V22 trimmed_gap10 |
| bounded_tracking_gap15 | 同一结构，仅短缺口上限为 0.15 s | V22 trimmed_gap15 |
| guarded_fusion_gap10 | 上述跟踪支路与 V22 原支路按预定义质量/运动共识守护选择，保留信号层回退 | V22 trimmed_gap10 |
| guarded_fusion_gap15 | 同一结构，仅短缺口上限为 0.15 s | V22 trimmed_gap15 |

固定锚定参数为截止频率 0.15 Hz、4 阶因果 Butterworth；守护参数为 min_tracked_fraction=0.60、max_reset_fraction=0.05、switch_score_ratio=1.15、max_branch_disagreement_bpm=12。两种结构乘两个 gap，共四个模式，本轮不增加参数网格。主方案已经指定，不能评分后将最优项改名为原定默认方案。所有候选、失败案例和诊断均保留。

开发可以利用已有结果理解失败机制，但推理不能读取真值，也不能用真值挑窗口、追踪参数、支路、心率频段或对齐偏移。下一轮若继续修改，应另建带版本的开发记录；重新跑同一批视频不会使其成为未知测试集。

## 固定来源与参考边界

沿用原六个完整来源，按 V22 冻结清单核对路径、大小、SHA-256、帧数和时间轴。

| 来源 | 计划窗 | 参考及用途 |
|---|---:|---|
| user0904 | 39 | 无参考；只能评价输出覆盖、连续性和机制行为 |
| user0907 | 42 | 无参考；不能根据输出更连续声称更准确 |
| ubfc | 44 | 配套设备 HR，采用既有同步与 10 s 均值口径；不是 ECG |
| kaggle_full | 419 | 无参考；保留完整原片，不能用 first60 作为额外样本 |
| synthetic72 | 11 | 已知 72 bpm 调制的工程控制，与真人分开 |
| data1 | 42 | 用户指定 Polar 设备 HR；同步来自文件时间估计，非硬件同步 |

合计 597 个高度重叠的窗口，来自 5 段真人采集和 1 段合成片；不能表述成 597 个独立样本、受试者或训练记录，也没有证据保证这 5 段对应 5 名不同的人。所有视频都已在此前研究中查看，最终冻结重跑属于回归验证。排除转码、播放版和裁剪副本；不读取、寻找或恢复已删除的 `_gudb`。

UBFC 按原规则合并设备重复时间戳，使用有效正 HR 的窗口均值。data1 完整复用 [原对齐协议](../rppg_data1_20260909/alignment_protocol.json)：UTC 起点为 `1788939171166718500 ns`，先以整数减去起点，再换算秒；导出 UTC 用 nullable Int64。主结果固定 shift=0，同时完整报告 −5、−2、−1、0、1、2、5 s，不能选择误差最小的偏移。参考窗口需处于覆盖范围、包含至少两个有效值，data1 内部间隔不得大于 2 s。

这批数据没有合格的同步波形形态真值；`r_wave` 应为 NA。能算设备 HR 参考不等于原始生理波形质量已经审核。无参考片的 MAE、RMSE、P5、R5、LoA 和参考 H1 SNR 为 NA，不能填零。

## 统一窗口与指标

保持请求窗长 10 s、步长 1 s；实际采用 `round(10×fps)` 帧和 `round(fps)` 帧。窗口中心为 `(起始帧+窗长帧数/2)/fps`。参考仍按该中心名义 ±5 s，不能悄悄改成实际帧区间后重新计算。UBFC 的实际窗长约 10.0123 s、实际步长约 0.9910 s，均须披露。短缺口上限采用 `floor(gap×fps)` 帧。

最终 HR 从真实保存的 `base` 波形读取，主读出为 `offline_ridge`，`local_peak` 完整报告并作为非退化检查。离线波形与 DP 不能称为实时系统。保留 POS、CHROM 和 fusion 分支，门槛针对 fusion；拒判窗口即使留有局部峰诊断值，也不能计入输出。

| 指标 | 分母与含义 |
|---|---|
| Nplanned / Nref | 全部计划窗 / 与候选无关的参考合格窗 |
| Noutput / Nvalid | accepted 且预测有限 / 同时参考合格 |
| MAE / RMSE | 有效窗口上预测减参考的绝对误差均值 / 均方根误差 |
| P5 | 误差 ≤5 bpm 的窗口数除以 Nvalid |
| R5 | 同一正确窗口数除以全部 Nref；拒判会降低此指标 |
| C_out / C_ref | Noutput/Nplanned；Nvalid/Nref |
| Bias / 描述 LoA | 平均有符号误差；Bias ±1.96×样本 SD |

LoA 是描述性范围，不是总体 95% 置信区间；重叠窗不能当作独立观测。另报 P10、R10、95 分位和最大绝对误差。

每个候选与同 gap V22 均须报告自身窗口、双方共同窗口、新增窗口和丢失窗口。共同/新增/丢失由输出掩码定义，不能按误差好坏划分。各子集保留原完整 Nplanned/Nref；因此共同窗 R5 仍以全参考窗为分母。正确窗口增减须满足：

`新正确−旧正确 = 共同窗正确增减 + 新增正确 − 丢失正确`。

所有模式共同窗口可附带展示，但门槛使用一对一同 gap 交集，不能让不相关候选缩小主比较范围。空参考或空共同有效窗不能成为通过门槛的捷径。

## 覆盖与空缺必须分别测量

HR 报输出覆盖、连续输出段数、断点、最长连续输出中心跨度、所支持原视频区间的并集，以及最长连续拒判窗数。最长 HR 拒判按“拒判窗数×实际步长”记决策网格时长，同时报首末拒判中心跨度；它不是视频上没有生理信号的唯一解释。

实际波形按整个保存样本轴统计有限样本比例、有限秒数、最长有限段、最长缺失段和内部最长缺失段。边界缺失包含在整体最长空缺内。秒数为样本数/fps，不能把重叠的 10 s 窗直接相加。

同时保留自身生成窗口数及比例、已生成但 HR 拒判数、仅由邻窗覆盖数，以及 observed/interpolated 样本比例。有限覆盖、原始观测、插值和“这一个窗口生成了波形”是不同指标。不能用前值保持或构造波形冒充新的有效监测。

机制审计记录人脸检测/跟踪、RGB 有效掩码、跟踪/筛选/回退/无效帧及 ROI 数、支路选择和拒判原因。原因可能重叠且存在判断顺序，不应强行解释成互斥物理原因。

参考 H1 SNR 完全复用 V22：全窗去均值，periodic Hann，单段谱，NFFT 至少 8192，0.7–3.5 Hz 总频带，以参考 HR 对应 H1 ±0.1 Hz 为信号带、剩余带为分母。只在 accepted、完整有限波形且参考合格时计算，报告可计算窗数、自身和配对窗口及配对 ΔSNR。不能改用算法自己选中的峰。该 SNR 不证明脉搏形态恢复。

## V24 默认升级规则

以下规则分别应用于已预声明的 gap10 主候选和 gap15 对应选项，各自与同 gap V22 比较。固定数值容差为 `1e-6`；严格改善须超过此容差，它不是已验证的临床或工程意义阈值。

1. **主读出精度同时改善。** UBFC 与 data1 每段等权：宏 MAE 为两段 MAE 的平均；总体 RMSE 为 `sqrt(mean(各段 RMSE²))`，即先等权平均各段 MSE 再开根号。自身窗和一对一共同窗的这两个总体误差都须严格下降；各参考段的自身/共同窗 MAE、RMSE 均不得增加。
2. **局部峰防退化。** 每段有参考真人视频的 local_peak 自身/共同窗 MAE、RMSE 不得增加，不要求每段或此读出严格下降。
3. **正确输出保留。** 两个读出的每段有参考视频自身 R5、共同窗 R5 均不得下降。所有参考分母固定，不能靠拒绝困难段美化误差。
4. **真人覆盖同时改善。** 五段真人视频分别等权平均 HR 输出覆盖与有限保存波形覆盖；两个宏平均都须严格提高，每段对应覆盖均不得下降。Kaggle 较长，不能按窗口数量让它主导宏平均。读出掩码如有差异，两个读出的覆盖都检查不退。
5. **合成控制保持。** synthetic72 不进入真人宏平均；两个读出的自身/共同窗误差、R5、输出覆盖及实际波形覆盖均不得退步。原误差为零时保持即可，不能要求低于零。
6. **工程证据完整。** 全部模式和来源执行成功；输入、候选参数及源码与推理前清单匹配；V22 基线复算一致；真实保存波形的 HR 重读、缺失/来源/回退审计及独立统计核对通过。

最长空缺与 SNR 必须完整报告；本次 V24 主门槛没有把它们增加为未声明的否决条件。另行套用 [V23 原门槛](../rppg_motion_v23/evaluation_upgrade_criteria.json) 并独立报告结果，其每例最长空缺、配对 SNR、合成 ≤1 bpm 与原“1 bpm 或 5 个百分点”有意义改善条件全部保留。V23 与 V24 包含不同约束，不应声称两者在数学上必然严格包含。V24 有意变更的后端模块在兼容报告中列明，不伪称未改。

若 V24 主门槛未过，保留现有生产入口，候选可明确命名为实验版本。即使通过，也应如实说明只有现有小规模回归集证据、data1 同步仍为估计，并单独完成安装后核验；评测器本身不部署、不切换默认入口。

## 评价器适配与最终验证

JSON 已给出四个模式的目录、baseline 和 gap 映射，预留 `--validation-root` / `--output`。新评价器可复用哈希固定的 V22 纯评分函数，但不能直接继承 V23 硬编码候选名、V23 source hash 或“全部后端不变”的断言。旧基线按 V22 清单核对；新代码按 V24 推理前 `protocol_before_validation.json` 核对，并与本方案绑定的 11 个源码哈希对账。意图改变的信号有效性必须计入比较，不能因未与 V23 相等而把结果排除。

最终流程为：确认参数及主候选 → 冻结代码/测试/输入/参考/评价器哈希 → 不读参考生成全部预测 → 检查保存波形与 HR 契约 → 统一评分全部候选及七个偏移 → 独立复算分母、配对增减、宏平均、UTC 与 SNR → 输出各门槛结果。输出目录存在即报错，防止覆盖旧证据。本轮参数已经确定；正式评分仍须等待全部预测和独立波形重读回执完成。

预期产物包括自身/共同/成对/新增/丢失误差表、宏平均表、连续性和实际波形表、全部偏移敏感性、逐窗参考与预测、回退审计、来源清单和两个独立门槛 JSON。每项结论均绑定最终输入与脚本哈希；若继续开发，旧轮次仍完整保留。
