# rPPG 运动监测：V2 代码升级与指标变化

**本次实现了多区域抗干扰实验分支，验证结果是“参考基频谱质量略有改善，心率精度及输出覆盖退步”。目前不能宣布运动中高质量 PPG 监测已实现，新的 fusion 分支不替换旧默认入口。**

研究目标统一为：运动过程中，提取接近真实脉搏成分的 rPPG 波形，并持续给出可信的心率。当前摄像头路线评价的是非接触 rPPG/BVP；它的结果不能直接等同于接触式反射 PPG 硬件系统性能。

## 1. 代码实际改了什么

| 更新 | 对目标的作用 | 本次验证边界 |
|---|---|---|
| 额头、左右脸颊独立采样和独立 POS/CHROM | 避免先平均 RGB 时让一个污染区域直接影响所有区域 | 采样可用率与旧版相同；不是人脸检出率提升 |
| 至少两个不同区域支持同一候选频率 | 利用空间冗余对付局部干扰；同一块皮肤的两种算法只算一个区域 | 共同运动仍可能得到错误共识 |
| 竞争峰歧义拒绝、失锁与重捕获 | 不强行对不明确的窗口报心率，不用旧值补齐拒绝窗口 | 拒绝更多不等于更正确，必须同时看 R5 与覆盖 |
| 运动频率重叠软降权 | 把运动信息用作辅助证据 | 不直接删除与运动同频的脉搏成分 |
| 稳健归一化、极性对齐与实际波形融合 | 尝试保留实际信号中的脉搏成分和谐波 | 未证明形态保真，幅值与极性无生理标定 |
| 固定窗口与独立评分、缓存校验和源文件哈希 | 每次升级均可追踪“哪里增、哪里减” | 不以平滑程度或非空输出作为精度 |

已通过 21 项测试（19 项采样/融合逻辑、2 项入口边界回归），完整运行 5 段保留视频；旧 POS/CHROM 心率及参考 SNR 复算与此前结果一致，新采样下的同算法对照也一致。新算法参数在首次真人参考评分前冻结，没有依据这一个 UBFC 视频调参。首次评分后修复了短视频带参考时的空表类型、6秒小数帧率的最小窗长处理，随后全量重跑；10秒默认运行的心率与波形数值未改变。首次冻结记录保存在 validation_initial，最终交付记录在 validation。

## 2. 以后围绕什么指标判断升级

令 `Nplan` 为全部计划窗口；`Nref` 为参考心率可计算的窗口；`Nvalid` 为参考可计算且算法接受并输出有限心率的窗口；`N5` 为其中绝对误差 ≤5 bpm 的窗口。这里的参考“可计算”不等于已经独立认证参考传感器质量。

| 层面 | 指标 | 定义及方向 | 当前可否测量 |
|---|---|---|---|
| 波形主指标 | 参考基频 SNR、配对 ΔSNR | `10log10(参考基频带功率/其余带内功率)`；越高越好，变化用 dB | UBFC、已知调制频率合成样本可算 |
| 波形形态 | 波形相关系数 r、归一化误差、逐搏检出率 | 与同步接触 PPG 在预先固定的滤波、对齐协议下比较 | 本轮没有通过校验的同步形态真值，填 NA |
| HR 主指标 | MAE / RMSE | `mean(abs(预测−参考))` / `sqrt(mean((预测−参考)^2))`；越低越好 | UBFC 可算；合成自检单列 |
| HR 命中 | P5 | `N5/Nvalid`；接受的结果中有多少在 ±5 bpm 内，越高越好 | 无参考时 NA |
| 监测主指标 | R5 | `N5/Nref`；所有参考可计算窗口中有多少给出正确结果，越高越好 | 能同时约束准确与拒绝，不因只挑容易窗口而虚高 |
| 覆盖约束 | C_out / C_ref | 有限且接受的输出数/Nplan；Nvalid/Nref，越高越好但不等于准确 | C_out 所有视频可算，C_ref 需参考 |
| 一致性辅助 | Bias、Bland–Altman LoA | 偏差及 `Bias ±1.96×样本误差标准差` | CSV 已输出；单视频重叠窗只作描述 |
| 运行辅助 | RGB/区域可用率、波形生成窗比例、延迟 | 区分采样、实际生成、邻窗覆盖、拒绝和失锁 | 可记录；整条处理链目前仍是离线 |

**建议的下一阶段原型验收目标（研究设计目标，不是行业标准，也不是已经达到的指标）：**在独立、同步参考的运动测试集上，MAE≤5 bpm、RMSE≤8 bpm、P5≥90%、C_ref≥90%、R5≥80%；相对预先固定基线，共同窗配对 ΔSNR 中位数争取 ≥3 dB，同时不降低 R5。静态集 MAE 恶化超过 0.5 bpm 应阻止替换默认分支。正式实验前固定这些阈值，并按运动强度和受试者分别报告。

## 3. 真人参考视频：指标有没有涨幅

可用于本轮真人精度比较的是 **UBFC subject1 单段视频**，参考为配套设备心率，不是 ECG。44 个计划窗口，窗口重叠，不能当作 44 名独立受试者。它不能覆盖用户目标中的全部运动条件。

| 指标 | 旧 POS + 离线 DP | 旧 CHROM + 离线 DP | V2 fusion 前向候选 | 相对旧 POS 的变化 |
|---|---:|---:|---:|---|
| 接受窗口数 | 40/44 | 40/44 | 35/44 | 少 5 窗 |
| C_out = C_ref | 90.91% | 90.91% | 79.55% | −11.36 个百分点 |
| MAE ↓ | 2.561 bpm | 2.545 bpm | 3.660 bpm | +1.099 bpm，误差增加约 42.93% |
| RMSE ↓ | 3.061 bpm | 3.141 bpm | 5.376 bpm | +2.315 bpm |
| P5 ↑ | 97.50% | 87.50% | 68.57% | −28.93 个百分点 |
| R5 ↑ | 88.64%（39/44） | 79.55%（35/44） | 54.55%（24/44） | −34.09 个百分点 |
| 各自可评分窗口 H1 SNR 中位数 ↑ | −4.509 dB（40窗） | −3.675 dB（40窗） | −2.979 dB（35窗） | 窗口集合不同，需看下方配对结果 |

为排除“只保留更容易的窗口”造成的偏差，再比较共同的 35 窗：POS DP MAE 为 **2.362 bpm**，CHROM DP 为 **2.401 bpm**，fusion 为 **3.660 bpm**。旧 POS/CHROM 的局部谱峰法在相同 35 窗的 MAE 分别为 2.789/2.684 bpm，也低于 fusion。因此退步不能仅归因于旧 DP 使用了未来窗口。

在同样的 35 窗上，逐窗计算 `SNR_fusion−SNR_旧版` 后取中位数：相对 POS 为 **+1.118 dB**，相对 CHROM 为 **+0.787 dB**；分别有 80.00% 和 71.43% 窗口变好。这是本轮有实测支持的波形频谱增益，不是整体识别准确率提升，也不能解释为运动伪影能量被准确测出或脉搏形态已恢复。配对差的中位数不等于两列中位数相减。

fusion 的 35 个接受窗口中，34 个自行生成融合波形；另外 1 个由相邻窗口的重叠贡献得到完整波形。生成比例为 34/44=77.27%，不能用 92.05% 的有限波形采样比例代替。

## 5. 已知脉搏与运动频率的仿真

另做固定随机种子 20260908 的 60 秒 RGB 混合仿真：脉搏 96 bpm、干扰 132 bpm（同频场景另设 96 bpm），每场景 51 个计划窗口。直接模拟 RGB 信号，不包含真人皮肤光学、摄像头压缩、表情或完整人脸运动；不能替代真实运动验证。

| 场景 | POS / CHROM / fusion MAE（bpm） | POS / CHROM / fusion H1 SNR 中位数（dB） | 结论 |
|---|---|---|---|
| 无运动污染 | 0 / 0 / 0 | 9.617 / 9.616 / 9.613 | 基本持平 |
| 只污染一个区域 | 36 / 0 / 0 | −4.143 / 7.119 / 9.569 | fusion 对比 POS 修正了误选；相对 CHROM 的 SNR 增加约 2.45 dB |
| 三个区域污染强度不同 | 36 / 0 / 0 | −5.701 / 7.623 / 6.302 | fusion 心率正确，但波形 SNR 比 CHROM 低约 1.32 dB |
| 全区域强共同污染 | 36 / 0 / NA | −9.443 / 8.547 / NA | fusion 全部拒绝，覆盖与 R5 都是 0，不能算改善 |
| 脉搏与运动同频 | 0 / 0 / 0 | 9.597 / 8.539 / 8.526 | 未硬删除同频分量；频率正确不能证明脉搏与干扰已分离 |

除“全区域强共同污染”的 fusion 外，各分支均接受 47/51 窗。拒绝输出时 MAE 为 NA，而不是 0。结果表明多区域方案对特定局部污染有价值，也暴露了共同运动下的不足。

## 6. 如何继续提高而不虚报涨幅

这轮先保留三区域输入、诊断和统一评分能力；fusion 作为实验分支，旧入口继续使用。SNR 提高而 HR 变差，说明“参考基频带功率相对其余带内功率提高”和“候选峰选对”是两个不同环节，下一版需要分别优化和消融。

优先增加带同步接触 PPG/HR 的运动视频，并把调参受试者与测试受试者分开。固定静止、转头、说话、手持相机运动、运动后恢复等场景，记录参考质量、光照和相机设置。在独立验证集上检验区域选择、全局共同运动干扰、候选跟踪三部分；不能继续只在这一个已看过的 UBFC 视频上追逐更低 MAE。
