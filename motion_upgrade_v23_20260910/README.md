# rPPG V2.3：皮肤小块跟踪与局部运动筛选候选

本版本以 V2.2 为基线，独立实现受 hschn58/rPPG 启发的前后向 LK 像素跟踪和局部异常筛选。它不是上游代码的原样复现，也没有把上游相关论文的硬件精度当作本版本成绩。具体是否适合作为默认版本，由同目录冻结判据和完整视频对照决定。

## 方法

- 保留 V2.2 的三 ROI、人脸检测/短时几何跟踪、像素合法性和质量门槛。
- 每个 ROI 在上一帧放置最多 100 个均匀小块中心，前向 LK 后反向返回，容许往返误差不超过 0.5 个缩小图像像素。合法零误差点保留，越界/跟踪失效点被剔除。
- 在原分辨率 RGB 上以浮点双线性插值采样 7×7 小块，只比较同一组相邻帧对应的小块。每帧重新播种，短暂丢失不会让该像素整段历史被删除。
- `tracking_only` 对配对小块的 RGB 对数变化做固定 10% 截尾均值；`tracking_screened` 先按相对共同颜色变化的距离，用 3×MAD 尺度筛选局部异常，再同样聚合。共同颜色变化保留，不能据此声称抑制了所有周期运动或光照。
- 至少需要 12 个可用配对小块；不足时明确回退到相邻基线 ROI 均值的变化。空档后重置，禁止跨缺失帧积分。
- 最终候选 RGB 是逐帧相对颜色变化重建的运动补偿信号，不是原始相机颜色。原始基线均值保存在 `baseline_*` 列；积分漂移与回退时的运动噪声是待测局限。
- 后端 POS/CHROM、滤波、ROI 融合、10 秒窗口/1 秒步长、从实际保存波形读出 HR 的规则均保持不变。所有推理不接收真实 HR/参考波形。

## 运行

安装后的明确实验入口为：

```bash
./run_motion_v23_experimental.sh /absolute/path/video.avi --output /absolute/path/new_result
```

该入口默认指定 `--pixel-mode tracking_screened --max-gap 0.10`。消融模式为 `--pixel-mode tracking_only`；`--max-gap 0.15` 为单独的连续性选项，不能逐片挑最好结果合并报告。

直接调用 `analyze_motion_v2.py` 默认仍为 `--pixel-mode disabled`，以便验证原采样回归。生产分析会先进行原人脸/ROI 提取，再重新解码视频进行像素处理，属于离线两遍处理。评测可使用经文件/源码身份验证的 V2.2 几何缓存，确保两版本的检测决策一致。

## 输出与解释

V2.2 的波形 CSV、心率 CSV、逐窗拒绝原因、summary 和图继续输出。额外字段包括各 ROI 的 `pixel_source`、种子数、通过点数、光流/几何/颜色/筛选拒绝数、对数颜色增量和重置标记。

`tracked_ratio` 表示使用有效配对小块；`baseline_ratio_fallback` 表示退回原 ROI 采样；`baseline_reset` 是首帧或缺口后起始；`missing` 仍无测量。回退不会被计入像素跟踪成功。`rgb_valid` 沿用真实图像可采样资格，不是 PPG 质量认证；补偿颜色有限也不能证明频谱主峰来自心跳。

## 验证

固定六个来源（五段真人视频和一个合成控制），两种像素方法、两种缺帧上限，总计 24 组结果。用相同时间窗和原参考协议比较误差、R5、实际波形/HR 覆盖率、最长中断、共同窗与新增/丢失窗质量。data1 使用原估计同步与全部七个时间偏移敏感性，不依据结果选同步。无参考视频不报告准确率。

默认升级候选预先指定 `tracking_screened_gap10`，对照 V2.2 `trimmed_gap10`；通过条件见 `evaluation_upgrade_criteria.json`。通过仅表示当前开发/回归片段的改进，不能当作独立受试者泛化验证。若门槛未通过，保留独立实验入口和全部结果，旧入口继续使用。
