# rPPG 研究：指标与算法更新的两张思维导图

研究主线：通过更新代码，提高运动过程中 PPG 信号的监测质量，分别观察波形、心率及连续输出表现。

## 思维导图一：我的指标及其含义

```mermaid
mindmap
  root((运动中高质量 PPG 监测))
    波形质量
      参考基频 SNR
        参考脉搏频率附近功率与其余带内功率之比
        越高越好，变化用 dB
      波形相关系数 r
        估计波形与同步参考波形是否相似
        固定极性及对齐后，越接近 1 越好
      波形归一化误差
        归一化后，两条波形相差多少
        越低越好
      逐搏检出率
        每一个真实脉搏是否被找到
        漏搏和误检越少越好
    心率质量
      MAE 平均绝对误差
        每个窗口预测心率与参考心率的平均绝对差
        越低表示平均心率误差越小
      RMSE 均方根误差
        对少数特别大的心率误差更敏感
        越低越好
      P5 命中比例
        有效输出中，误差不超过 5 bpm 的比例
        越高越好
      Bias 与 Bland–Altman
        Bias 表示系统性高估或低估
        偏差接近 0，误差一致性界限越窄越好
    连续监测能力
      R5 正确输出比例
        所有参考可计算窗口中，正确输出的比例
        同时考虑测得准与能测到
      输出覆盖率
        全部计划窗口中，有效心率输出的比例
        覆盖高不等于准确
      波形生成比例
        真正产生融合波形的窗口占比
        与相邻窗口填出的有限波形分开统计
      失锁恢复和延迟
        干扰结束后多久恢复输出
        结果从采集到可用需要多久
    测量条件
      心率误差需要同步 HR 或 ECG 参考
      波形形态需要同步接触 PPG 参考
      无参考时精度指标填 NA
      新旧使用相同视频及窗口协议
```

分母约定：`Nplan` 是全部计划窗口；`Nref` 是参考心率可计算窗口；`Nvalid` 是参考可计算且算法接受并输出有限心率的窗口；`N5` 是其中绝对误差 ≤5 bpm 的窗口。`P5=N5/Nvalid`，`R5=N5/Nref`，`C_ref=Nvalid/Nref`。参考可计算不等于参考质量已经通过独立认证。

## 思维导图二：算法更新后的性能提升及后续方法

```mermaid
mindmap
  root((V2 更新效果与下一步))
    已完成的方法
      额头与左右脸颊独立采样
      各区域分别提取 POS 和 CHROM
      至少两个区域形成频率共识
      歧义拒绝与失锁重捕获
      运动频率软降权与实际波形融合
    已观察到的提升
      UBFC 波形频谱
        共同 35 窗，相对旧 POS 的配对 SNR 增益中位数为 1.118 dB
        相对旧 CHROM 为 0.787 dB
      局部污染仿真
        单区域污染时，fusion 的 MAE 为 0 bpm
        比 CHROM 的 SNR 高约 2.45 dB
    仍需改善的表现
      MAE 从 2.561 增至 3.660 bpm，误差增加约 42.9%，属于退步
      RMSE 从 3.061 增至 5.376 bpm
      R5 从 88.64% 降至 54.55%
      输出覆盖从 90.91% 降至 79.55%
      全区域强污染仿真中，fusion 全部拒绝
    后续方法与对应指标
      第一步 补齐同步参考
        同步记录视频与接触 PPG 或 HR
        按受试者拆分开发集与独立测试集
        让运动视频的误差和波形指标可以计算
      第二步 改进区域选择
        结合遮挡、饱和、模糊及运动程度分配权重
        对照单区域、直接平均及自适应融合
        检验 SNR 与波形生成比例
      第三步 优化候选选择与失锁规则
        保留多个候选，识别共同运动形成的假共识
        在开发集校准拒绝与重捕获条件
        同时检验 RMSE、P5、R5 和覆盖
      第四步 验证实时处理
        将离线滤波替换为可因果运行的处理
        单独测量延迟与恢复时间
        同时检查波形及心率性能变化
    证据边界
      真人精度结果仅来自 UBFC subject1 单段视频
      三段真实运动视频没有同步参考，不能计算精度增幅
      72 bpm 合成自检新旧 MAE 都为 0，没有涨幅
      当前整条链路仍为离线处理
```

第二张图的真人数值默认对比“旧 POS + 离线 DP”与“V2 fusion 前向候选”，SNR 采用共同窗口逐窗配对差的中位数。仿真是已知频率的 RGB 混合信号，不能代替真人运动验证。

目前波形相关系数、形态误差和逐搏检出尚未获得经校验的同步形态参考，不能列作已经提升的指标。下一步方法为待实施的更新方案，不代表已经完成。
