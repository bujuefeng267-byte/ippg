# 论文关联与性能证据核查

核查日期：2026-09-10。仅使用仓库固定版本及期刊官方材料；未运行仓库代码。

**结论：这是与论文作者及研究工作相关的 RGB-rPPG 项目，但现有证据不能把整篇论文的硬件系统性能当作该代码的成绩。**

1. 仓库 README 的原意是本工作“参与／贡献于”该论文，并属于 UW–Madison Yu Group 更广泛的生物测量研究；它没有声明当前完整软件版本就是论文全部实验的复现。核对版本为 `8dd44360d159eccde7f85a5a6542e3b44c621029`。[固定 README](https://github.com/hschn58/rPPG/blob/8dd44360d159eccde7f85a5a6542e3b44c621029/README.md)

2. 论文确已发表：2026-01-13，Nature Sensors 1，155–162。作者中有 Henry Schnieders；作者贡献将 H.S. 列为 PPG 数据处理及校准参与者。但论文 **Code availability 指向 `zshao56/Lock_in_Bio`，不是 `hschn58/rPPG`**。这支持作者和研究关联，尚不能证明两个仓库的实现或版本等价。[论文官方页](https://www.nature.com/articles/s44460-025-00012-0)

3. 论文核心是**主动调制不同波长照明、同步锁相探测的高光谱成像硬件**，重点抵抗环境光变化。摘要报告 HR 误差低于 3 bpm，并用 660/940 nm 双波长验证血氧；ECG 和血压属于基于 rPPG 的机器学习重建。它们不是普通 RGB 摄像头直接测 ECG，也不是当前仓库在运动视频上的 MAE。原始人体 PPG 因隐私不公开，官方声明另提供合成数据，故公开代码演示也不能自动复现人体实测结果。[论文摘要与数据声明](https://www.nature.com/articles/s44460-025-00012-0)

4. 官方补充材料 S11/S12 展示阅读、睡眠、游戏和说话，主要讨论光照变化；这些材料不足以支持跑步、大幅头动等强运动条件下的泛化结论。S10/S16 描述对齐和归一化后的周期对，并使用其中 80% 训练；仅凭这一描述不能确认按受试者隔离的测试。S7 的 SNR 来自暗室光功率实验中的像素信号与跨帧噪声，**不能和本项目“参考心率 H1 邻域／其余带内能量”的频谱 SNR 直接比较**。[官方补充材料，S7、S10–S12、S16](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs44460-025-00012-0/MediaObjects/44460_2025_12_MOESM1_ESM.pdf)

本次已读取官方摘要、作者贡献、数据／代码声明与 23 页公开补充材料；未取得订阅正文，因此不补推未核实的样本量、参考设备型号或受试者拆分。建议将该仓库称为“论文相关作者公开的 RGB-rPPG 管线”，其效果仍需在固定视频、参考、窗口与覆盖率协议下独立评价。
