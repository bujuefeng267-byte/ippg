# V27：稳定局部皮肤块的运动 rPPG 实验

目标是提高运动过程中可用的脉搏信号和心率估计。这版保留像素跟踪、局部异常筛选、跟踪失败回退，将原先过早平均的局部颜色轨迹保存下来，再比较不同的空间汇总方法。

本版是实验版本。六段开发视频的实际得失、是否满足升级条件，以 `results/data1_6_v27_20260912/final_report/` 的完整报告和原始 CSV 为准。不能由代码结构、合成测试或外部论文的成绩推断本项目已经提高准确率。

## 做了什么

| 环节 | 实现和作用 |
|---|---|
| 固定小块 | 额头、左右脸颊各 4 个，共 12 个；初次可靠检测建立局部关键点锚定，小块身份在检测缺口后保留 |
| 运动跟踪 | 用前后向光流检查跟踪可靠性，记录同批位置前后的 RGB 变化 |
| 局部异常筛选 | 在各小块内部排除异常颜色变化，避免一处阴影或局部遮挡直接污染整脸 |
| 失败回退 | 跟踪失败时回到同一小块的实测颜色；没有可靠皮肤观测时保留缺失并重置积分 |
| 独立提取 | 各小块分别经过原有锚定校正和 POS/CHROM，保存可检查的颜色、BVP 和来源标记 |
| 空间汇总 | 对照“先合并颜色”和“各小块先提取 BVP”；各大区域的贡献等权，避免小块多就获得过多票数 |
| 心率聚合 | 对照区域分层中位数与完整功率谱的固定聚类；要求至少两个大区域参与 |
| 运动与时间 | 对同一保存的融合波形，分别开关原有运动证据与相邻时间窗修正，形成独立对照 |

完整频谱聚类采用本项目独立实现的 complete-link 规则，不是 pyVHR 原作者的精确复现；没有搬用作者数据集上的 1.70 bpm 当作本项目误差。

## 结果应当怎样读

空间汇总得到的 `heart_rate.csv` 是各小块心率的统计结果；中位数可能落在两个候选频率之间。它没有被用于合成脉搏波，也不代表融合曲线一定具有相同主频。

`waveform.csv` 是实际小块 BVP 的归一化宽带混合，`fusion_heart_rate.csv` 则是从这一条保存波形重新提取的心率。两种心率分开输出。融合波形没有接触式 PPG 真值，因此只能报告可用性和处理来源，不能宣称脉搏形态、幅值或 SNR 已经被验证。

缺失是 NaN 和明确的状态标记，图上留空；不会填零、延用上次心率或用参考心率补点。

| 指标 | 含义 |
|---|---|
| MAE / RMSE，bpm | 在有输出且有参考的同一时间窗中，心率误差的平均水平 / 对大误差更敏感的水平 |
| P5，% | 有效比较窗口中，绝对误差不超过 5 bpm 的比例 |
| R5，% | 全部有参考的计划窗口中，实际输出且误差不超过 5 bpm 的比例；缺失也计入分母 |
| 心率覆盖率，% | 全部计划窗口中，有被接受的心率输出的比例 |
| 融合波形覆盖率，% | 全部视频采样点中，保存了有限融合 BVP 数值的比例；不是波形正确率 |
| 小块可观测率，% | 每个固定小块获得有效皮肤 RGB 的帧比例；不等同于人脸检出率或心率正确率 |

六段视频使用相同的 10 秒窗、约 1 秒步长、42–210 bpm 范围。沿用此前的 309 个参考窗口和估计时间对齐，额外报告固定偏移敏感性，不根据误差选择最佳偏移。这些视频已参与过开发，不能当作独立泛化验证集；Polar 导出的参考值也不是逐采样 ECG 波形。

## 文件用途

- `stable_patch_frontend_v27.py`：原视频到固定小块 RGB、跟踪和几何记录。
- `prepare_patch_signals_v27.py`：小块锚定、early/late 对照输入和 POS/CHROM。
- `patch_hr_v27.py`：心率中位数、完整 PSD 聚类和实测宽带融合。
- `analyze_video_v27.py`：任意新视频的独立分析入口，具体参数见 `--help`。
- `run_v27.py`：本次六视频冻结实验的复现入口，依赖原项目清单，不用于任意新视频。
- `evaluate_v27.py`：冻结参考和旧版数据的评分、时间偏移敏感性及升级条件。
- `qa_v27.py`：独立核验。

批量实验输出目录已存在时会拒绝覆盖，避免新试验悄悄改写本次结论。原视频、V25、V26 和历次失败试验均保留。完整实验涉及全帧解码、12 块记录和离线时间窗处理，不保证实时速度。
